How the value is computed

{{FIT_FORMULA}}

  1. Comparables. Every protocol in the snapshot whose token trades and whose market cap is above zero ({{COMPS_N}} of them) anchors the fit. Protocols whose token already trades never appear on the board.
  2. Fit. Ordinary least squares of log market cap on a constant, log TVL and 7-day TVL growth (as a fraction). No hardcoded list of names: a protocol's value follows from its own TVL and growth.
  3. Implied value. The fitted value for the protocol, with the implied-to-TVL ratio clamped to 0.5%–75% so no row is priced at a multiple the comparables never support.
  4. Uncertainty. 200 seeded bootstrap refits of the fit. Each row shows its P10–P90 value interval and the rank range across refits.
  5. Farm economics. Deposit is sized by TVL tier ($500 below $25M, $1,000 below $100M, $2,000 below $500M, $5,000 above). Expected value is implied value times deposit over TVL. Costs are $30 to set up plus $5 to exit. Break-even is the deposit at which expected value equals cost. $/hour divides the net by the hours the plan takes (half an hour to set up, fifteen minutes to exit, ten minutes of checking per week).
  6. Verdict. FARM when the expected value reaches $170, THIN when it reaches $85, SKIP below that. A thin or skip row still shows its plan, with the warning in the steps.

Limits, stated plainly

The snapshot is a single day ({{AS_OF}}). A protocol can launch a token, change its TVL sharply, or turn out to have a token its DefiLlama record does not carry — the board says a protocol records no token, never that it has none. Implied value is this entry's claim about what a token would be worth if the protocol's record stayed as it is; it is not a prediction that a token will be issued, or when. Farm plans are sized for one reader doing the work by hand; they are not financial advice.
